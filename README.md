# monterssh

Тулза для монтирования проекта на компьютер по SSH.

CLI-утилита на PHP для управления SSHFS-подключениями на macOS.

## Требования

- macOS
- PHP CLI
- `sshfs` и macFUSE
- SSH-ключи в `~/.ssh`

## Запуск

```sh
php mount-sshfs.php
```

При первом запуске программа создаст локальный `data.json`. Файл содержит адреса серверов и параметры SSH-подключений, поэтому он исключён из Git.

## Команды

- `add` — добавить SSH-подключение
- `edit <номер>` — изменить подключение
- `delete <номер>` — удалить его из конфигурации
- `mounts` — показать активные SSHFS-точки
- `unmount <номер>` или `kill <номер>` — отключить выбранную точку
- `kill all` — отключить все активные SSHFS-точки в `/Volumes`
- `list`, `info`, `help`, `version`, `exit` — список, сведения и служебные команды

Можно смонтировать подключение по номеру из списка или запустить `php mount-sshfs.php <номер>`.

Проект основан на [mountsshfs](https://github.com/garrylie/mountsshfs) и развивается как `monterssh`.
