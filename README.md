# monterssh

Тулза для монтирования проекта на компьютер по SSH.

CLI-утилита на PHP для управления SSHFS-подключениями на macOS.

## Требования

- macOS
- PHP CLI
- `sshfs` и macFUSE
- SSH-ключи в `~/.ssh`

## Запуск

```sh
php mount-sshfs.php
```

При первом запуске программа создаст локальный `data.json`. Файл содержит адреса серверов и параметры SSH-подключений, поэтому он исключён из Git.

## Команды

- `add` — добавить SSH-подключение
- `edit <номер>` — изменить подключение
- `delete <номер>` — удалить его из конфигурации
- `mounts` — показать активные SSHFS-точки
- `unmount <номер>` или `kill <номер>` — отключить выбранную точку
- `kill all` — отключить все активные SSHFS-точки в `/Volumes`
- `list`, `info`, `help`, `version`, `exit` — список, сведения и служебные команды

Можно смонтировать подключение по номеру из списка или запустить `php mount-sshfs.php <номер>`.

Проект основан на [mountsshfs](https://github.com/garrylie/mountsshfs) и развивается как `monterssh`.

## Нативное приложение macOS

Требуются macOS 14+, Swift 6 (Command Line Tools), установленный SSHFS и macFUSE.

```sh
./scripts/build-app.sh
open dist/Monterssh.app
```

В приложении выберите «Настройки → Импортировать JSON» и укажите локальный
`data.json` из старого скрипта. Поддерживаются оба формата порта (число и строка),
полные пути `/Volumes/...` и имена публичных ключей `.pub` (используется приватная пара).
Повторный импорт пропускает существующие точки. Исходный JSON не изменяется.
Настройки и последние 200 событий сохраняются в `~/Library/Application Support/Monterssh`.

Для первого подключения подтвердите ключ сервера через обычный `ssh` в Терминале.
Ключ с паролем добавьте в SSH Agent (`ssh-add ~/.ssh/id_ed25519`). Поле ключа можно
оставить пустым для использования Agent. Приложение не сохраняет пароли и не
отключает проверку ключа сервера. При необходимости создать каталог в `/Volumes`
macOS запросит администратора.

Обычное отключение сохраняет защиту занятых дисков. Принудительное отключение
доступно отдельно в меню проекта. «Отключить все» работает с текущим списком SSHFS,
в том числе с внешними подключениями. APFS/NFS и другие диски не отключаются.
Закрытие окна оставляет приложение в строке меню; завершение приложения сохраняет mount'ы.

Сборка локально подписана ad hoc. Для распространения потребуется Developer ID и
нотаризация Apple. Приватные конфигурации не включаются в bundle или Git.

Проверки ядра:

```sh
swift run CoreChecks
```
